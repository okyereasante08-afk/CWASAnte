DERIVATIVES & INTEGRALS — QUICK REFERENCE
Trig · Inverse Trig · Hyperbolic · Inverse Hyperbolic
THE ONE RULE: Every “co-” function (cos, cot, csc & their inverse/hyperbolic cousins) has a NEGATIVE derivative. Everything without “co-” is POSITIVE.  •  Integrals = derivatives run backward. If $\frac{d}{dx}\tan x=\sec^2x$, then $\int\sec^2x\,dx=\tan x+C$. Don't memorize twice.

How the tracking works

Every question has its own mastery box, similar to a Leitner flashcard system (the same idea behind Anki, and behind key.br's progress tracking). Get a question right and it moves up a box — it'll be shown less often. Get it wrong and it drops back to box 0, so it resurfaces almost immediately and keeps coming back until you've actually got it, not just guessed it once.

Mixed drill pulls from all 54 questions, weighted toward whatever you're weakest on. Drill weak items restricts the session to things you've missed before or haven't reviewed in a while — use this the night before a test.

Progress is saved in your browser (localStorage), so it persists between visits on the same device but won't automatically sync across devices or to friends you share this file with — each person's copy tracks their own progress independently.
